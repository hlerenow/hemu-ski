# Lift pylon

Source: [Polyfork Lift Pylon](https://polyfork.dev/asset/lift-pylon-4e4385), free low-poly GLB. License: https://polyfork.dev/licensing. The game locally adjusts the head to a 6 m rope gauge and extends the lower mast for each support height.

- File: `lift-pylon-v01.glb`
- SHA-256: `cc1f8bac73a9530c7a667052fbe1cdeb77797f38cb28959c1806a9f64ecc5fd2`
- Original dimensions: 3.96 × 9.68 × 2 m; Y up, origin at ground, ropes run along Z.
- Original rope gauge: 3.6 m; rope height: 8 m.

- `lift-pylon-no-ladder-v02.glb`: generated from Polyfork's source with `ladder: false`; SHA-256 `964a1d50dea236f7f6bf11e13b94a40fea870e63fb65535fb9eeaf22f1cf34d1`. The game builds a fixed-spacing ladder and extends only the lower mast to reach each rope height. The original v01 is retained.
- `lift-pylon-no-sign-v03.glb`: v02 with the mast number board and frame removed; SHA-256 `fa0489dde688566889cce91157da5b0bd5ba73619a4d10d263a0bd8dc44670f4`.
