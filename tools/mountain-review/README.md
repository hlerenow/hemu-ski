# 远山审阅

运行 `npm run dev` 后打开 `/tools/mountain-review/`。

- 「旧远山 / 新远山」在同一相机位置切换原始远山与新版远山。
- 「实拍方向」近似复现用户照片（吉克普林峰顶，东北望西南）；「查看实拍」叠出照片对照。
- 四个固定机位覆盖山顶北、东、西侧和山腰下行视野。
- 晴天、阴天和夜间使用游戏的天气、雾和着色参数。
- 拖动环看，滚轮缩放；「进入游戏」打开实际游戏。

新版远山用 40 米 DEM（`public/data/backdrop-dem-v02.u16`，由
`tools/terrain/bake-backdrop.mjs` 生成），高程原样使用，不改顶点。
`src/world/terrain.js` 的 `createBackdrop()` 从 DEM 自身算出：每处在所在山体
中的相对高低（对比周围约 1.5 公里和 500 米的地面）、坡度，以及汇流图（D8，
即每处有多少上游地面的水流经，同 World Machine / Gaea 的 flow map）。
`src/world/mountain-material.js` 据此上色：山顶和上半段永远全白；岩石只沿
山体下半段中等大小的冲沟露出，成不规则、长短不一的条带，再由域扭曲噪声
（domain warping）去掉一部分、偶尔断开；山脚的大河谷和缓坡保持白雪。远山
不画树林。着色沿用游戏的三阶卡通色调；所有边缘至少宽一个像素，不会变成
颗粒噪点。

`baseline.js` 固定保存本次修改前的远山实现，仅用于对比。审阅页不参与生产构建。
